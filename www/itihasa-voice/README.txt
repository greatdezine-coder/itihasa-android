Itihasa offline voice pack
==========================
Keep this folder ("itihasa-voice") next to itihasa-v2.html. It lets the microphone
work with no internet. The speech models are OpenAI Whisper "base" and "tiny" (MIT licence),
converted to ONNX by Xenova (Hugging Face), run with Transformers.js and
ONNX Runtime Web (Apache-2.0 / MIT licences).
